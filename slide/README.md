# PQC 기반 ERC-4337 Smart Wallet Social Recovery 발표자료

GitHub Pages에 바로 올릴 수 있는 정적 HTML/CSS/JS 슬라이드입니다.

## 사용 방법

1. 이 폴더의 `index.html`, `styles.css`, `script.js`를 GitHub repository 루트에 업로드합니다.
2. GitHub repository → Settings → Pages → Deploy from a branch → `main` / root 선택.
3. 배포된 Pages URL로 접속하면 발표자료가 열립니다.

## 조작법

- 다음 슬라이드: `→` 또는 `Space`
- 이전 슬라이드: `←`
- 전체화면: `F`
- 인쇄/PDF 저장: `P`

## 구성

- `index.html`: 슬라이드 본문
- `styles.css`: 16:9 발표 디자인
- `script.js`: 슬라이드 이동, 진행바, 키보드 조작
